This wiki contains crisp concept notes for networking subtopics covered by the exercises. Each page is meant to provide the mental model and decision guide before going deeper into implementation or external resources.

## How To Use

Read the wiki page first, then open the matching exercise:

```text
wiki/<subtopic>.md
exercises/<subtopic>/README.md
exercises/<subtopic>/IMPLEMENTATION_GUIDE.md
```

The wiki explains what the concept is and when it matters. The exercise is where you build the smallest useful version.
