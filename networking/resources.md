# Networking Resources

## Articles

1. [Networking Essentials](https://www.hellointerview.com/learn/system-design/core-concepts/networking-essentials) - Hello Interview guide covering layers, DNS, TCP, UDP, HTTP, REST, GraphQL, gRPC, realtime protocols, and load balancing.
2. [MDN: Using server-sent events](https://developer.mozilla.org/en-US/docs/Web/API/Server-sent_events/Using_server-sent_events) - Practical guide to using SSE with the browser `EventSource` API.
3. [MDN: Server-sent events](https://developer.mozilla.org/en-US/docs/Web/API/Server-sent_events) - Overview of the SSE API and browser behavior.
4. [MDN: EventSource](https://developer.mozilla.org/en-US/docs/Web/API/EventSource) - Reference for the browser API used to receive server-sent events.
5. [WHATWG: Server-sent events](https://html.spec.whatwg.org/dev/server-sent-events.html) - HTML standard section that defines `EventSource` and the event stream format.
